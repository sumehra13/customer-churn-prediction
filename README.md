# Customer Churn Prediction

## Overview
This project uses machine learning to predict whether a customer is likely to leave a service (customer churn).

## Project Files
- `Churn_Data.csv` – Dataset used for the analysis.
- `predict_customerchurn.ipynb` – Jupyter Notebook containing the project code.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## How to Run
1. Download or clone this repository.
2. Install the required Python libraries.
3. Open `predict_customerchurn.ipynb` in Jupyter Notebook or Google Colab.
4. Ensure `Churn_Data.csv` is available in the notebook's working directory.
5. Run the notebook cells.

## Project Purpose
The project explores customer data and applies machine learning techniques to predict customer churn.
